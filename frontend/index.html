RELIABLE NETWORK PERSISTENCE

Keep wired captive sessions active without manual logins.

Campus, laboratory, and corporate wired networks protected by Sophos or Cyberoam gateways periodically expire user sessions. When links drop or expire silently, active downloads, SSH terminals, and background services fail. WiFi Agent senses link state, tests portal health, sends keep-alives, and logs in automatically only when required.

Carrier & Link Sensing

Distinguishes physical Ethernet link disconnection from portal session expiry. Avoids spurious login attempts when the cable is unplugged.

Zero Plaintext Credentials

Passwords are stored exclusively in the operating-system credential vault (Windows Credential Manager, macOS Keychain, or Linux Secret Service). Never saved to config files or logs.

Redirect-Immune Probing

Connectivity checks reject captive-portal HTTP 302 redirects, ensuring the agent only marks internet available when genuine public access is verified.

CORE SYSTEM ARCHITECTURE

Four engineered modules that monitor, authenticate, and protect your connection.

Built in Python 3.10+ with zero heavy dependencies. Operates as an unobtrusive background service using native desktop controls, process-level locks, and atomic state updates.

Interface Monitor

Detects active physical wired interfaces via psutil and sysfs. Filters out virtual and loopback adapters to lock onto the live Ethernet link.

Ethernet hardware carrier detection

OS Vault Manager

Reads credentials on demand directly from Windows DPAPI, macOS Keychain, or Secret Service. Passwords are never written to disk or status files.

DPAPI hardware-backed vault

Portal Client

Manages Sophos/Cyberoam XML keep-alives and authentications. Automatically redacts passwords and sensitive tokens before writing to diagnostics.

XML/HTTPS portal keep-alive & login

Supervisor Daemon

Applies bounded retry backoff, prevents duplicate daemon instances via process-scoped mutexes, and auto-starts via Windows Task Scheduler or LaunchAgent.

SingleLock crash-resilient mutex
